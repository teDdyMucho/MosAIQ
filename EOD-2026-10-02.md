## Bugs found and fixed

None of these were part of the plan — they surfaced during testing:

1. **The member-app gate never ran.** No `/app/*` page had the `appBody` class,
   so `requireLogin()` was dead code. Those pages were open to anyone.

2. **The browser could grant itself a membership.** The `update own profile`
   policy covered `is_member`, so anyone could unlock free access from the
   console.

3. **`set_subscription()` was callable by everyone.** Postgres grants EXECUTE to
   PUBLIC by default, so revoking from anon/authenticated alone left it
   inherited.

4. **Sign out did not sign anyone out.** It was a plain link to index.html — the
   session stayed alive afterwards.

5. **Public pages did not know you were signed in.** No auth.js, so they always
   showed "Log in". This was the cause of the "About tab auto-logs-out" report.

6. **Stale `rm_user` in localStorage.** Public pages read the old data while
   member pages asked Supabase — the two disagreed, which produced the repeated
   logouts.

7. **The trial CTA asked a signed-in user to sign up again.**

8. **Text behaved differently from Call.** It pointed at the public trial page,
   asking for a trial you had already paid for.

## Before taking real users

1. **Turn email confirmation back on** — it is OFF for testing, which means
   anyone can create an account using someone else's address. A real SMTP
   provider is also needed (Resend is free for 3,000/month); the built-in
   mailer allows roughly 3 emails per hour.

2. **Stripe** — there is no payment processor. Any card number is accepted, and
   **every visitor can claim a free trial**.

3. **`/app/*` is still gated client-side** — RLS protects the member *data*,
   but the HTML itself is served to anyone who requests it.

4. **The Delphi channel id is public** in `app/chat.html` — worth confirming
   with Delphi.
